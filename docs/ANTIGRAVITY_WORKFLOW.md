# Antigravity Workflow

## First prompt
Read `AGENTS.md`, `PRD.md`, and `docs/DESIGN_SYSTEM.md` before editing. Inspect the existing starter project. If UI UX Pro Max is installed, use it to validate the visual system. Report the project state and missing assets before making changes.

## Recommended task sequence
1. Audit starter and create implementation plan.
2. Validate dependencies and fix build/type errors.
3. Refine the visual design system and responsive shell.
4. Add a valid rigged GLB and inspect animation clips.
5. Build a reusable character animation controller.
6. Implement pointer/tap interactions.
7. Implement story scenes and scroll choreography.
8. Add photo modal and editable letter content.
9. Add audio controls and sound effects.
10. Optimize and test mobile/desktop.
11. Run production build and report remaining issues.

## Prompt template for each task
Read `AGENTS.md` and the relevant sections of `PRD.md`. Implement only this task: [DESCRIBE TASK]. Preserve the visual system and existing architecture. Inspect before editing. Do not fake missing assets or interactions. Run the relevant checks and report changed files, test results, and blockers.
